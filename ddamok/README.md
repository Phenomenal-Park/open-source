# 따목 (ddamok · タモク)

오목에 **두 점 따내기**를 더한 바둑판 게임. 같은 화면 2인 대국, AI 대국, 온라인 대국(레이팅·친선·친구매치)을 지원하고
Cloudflare(Workers + D1 + Durable Objects)에서 돈다. 점수는 18급~9단.

## 실행

Node 22.18 이상.

```bash
npm install
npm start          # 화면 빌드 + 로컬 Cloudflare(wrangler dev) → http://localhost:8787
```

로컬에서는 인증 메일 대신 화면에 "개발용 서버: 인증 코드 ……"가 뜬다.
화면만 고칠 때: `npm run dev:api`(API, 8787)와 `npm run dev`(Vite, 5173 → /api 와 WebSocket 프록시)를 함께 띄운다.
배포: [DEPLOY.md](DEPLOY.md)

## 온라인 대국

| | 상대 | 점수 |
|---|---|---|
| 레이팅매치 | 실력 점수가 가까운 사람: 0~5초 ±100, 5~15초 ±250, 그 뒤 ±500(더 오래 기다린 쪽 기준, 범위 안에서 가장 가까운 사람). 15초가 지나도 없으면 실력 점수가 가장 가까운 AI 3개 중 무작위 하나(프로필에서 끌 수 있음, 기본 켜짐) | 반영 |
| 친선매치 | 친선매치를 누른 사람 중 무작위 | 미반영 |
| 친구매치 | 같은 코드(숫자 1~8자리)를 입력한 사람 | 미반영 |

- 착수는 서버(대국방 Durable Object)가 규칙 엔진으로 검증한다. 한 수 시간 제한 없음. 무르기 없음, 기권 있음.
- 접속 끊김이 서버에 알려진 뒤 45초 안에 돌아오지 않으면 끊긴 쪽 패배. 사람·AI 대국 모두 한 수 시간 제한은 없다.
  - 연결이 닫히면 바로 알아챈다. 조용히 끊긴 경우(터널·앱 강제 종료 등)는 신호 확인으로 알아챈다:
    브라우저가 10초마다 신호를 보내고, 서버는 25초 동안 신호가 없으면 끊긴 것으로 보고 그때부터 45초를 센다.
  - 브라우저는 자동으로 다시 접속하고, 새로고침해도 진행 중인 대국으로 돌아간다. 매칭 대기 중 신호가 끊긴 사람과는 매칭하지 않는다.
- AI 상대는 서버가 둔다. AI 계정 점수도 사람과의 대국으로 갱신되어 AI 급수가 저절로 맞춰진다(순위표·9단 비율에서는 제외).
- 가입: 닉네임 · 이메일 · 비밀번호 + 만 14세 이상 확인 → 6자리 인증 코드(10분, 5회). 인증해야 온라인 대국 가능.
  로그인은 이메일 또는 닉네임.
- 기보: 닉네임으로 검색, 사람별 최근 100판(20판씩 더 보기). 목록은 요약 칸만 읽고 착수 데이터는 기보 상세에서만 읽는다.
  한 판 = 기보 1개(두 사람이 공유). 실제 삭제는 양쪽 최근 100판에서 모두 빠지고 누구의 명승부도 아닌 기보만.
  점수·최고 점수·통산 전적(승·패·무)은 계정에만 있어 기보 정리와 무관하다.
- 명승부: 1인 1판, 본인이 둔 끝난 대국(승·패·무 모두), 해제 전까지 평생 보관. 프로필·기보 화면에 상대 닉네임과
  대국 당시 상대 점수, "흑번 57수끝 오목승"·"백번 43수끝 돌따냄승" 식으로 표시(대국 당시 닉네임·점수를 기보에 함께 저장).
- 통산 전적은 레이팅매치 기준. 승률 = 승 ÷ (승 + 패 + 무)(무승부는 승리가 아님). 무승부 점수는 양쪽 0.5승(글리코), 연승은 끊긴다.
- 안내 페이지: 소개(/about) · 규칙(/rules) · 문의(/contact, 이메일은 빌드 시 `VITE_CONTACT_EMAIL`) · 개인정보 처리방침(/privacy).
- 광고 자리: 프로필·기보 화면만(페이지 전체를 새로 여는 링크 구조, 자동 새로고침 없음). 대국 화면에는 광고 없음.

## 규칙 구현 요점

- 포획은 **이번 착수점 기준**으로만 판정: `P(자기)-상대-상대-자기`, 8방향 각각 독립, 여러 방향 동시 가능.
  판에 `●○○●` 모양이 있다는 것만으로는 잡히지 않는다(자충·소급 포획 없음).
- 처리 순서는 지시서 §6 그대로: 착수 → 포획 수집·동시 제거 → 포획 수 → 포획 승리 → 최종 판에서 5목 → 차례 넘김.
- **정확히 5목만 승리**(§9-15, §11-4). 6목 이상은 둘 수 있으나 승리가 아니다. `overlineWins: true` 설정으로 바꿀 수 있다.
  같은 수에서 한 축은 6목, 다른 축은 정확히 5목이면 그 5목으로 승리.
- 금수 없음(33·44·장목 모두 허용, 흑백 동일).
- 판이 다 차서(포획으로 생긴 빈칸도 없음) 승자가 없으면 무승부(`winReason = "draw"`, `winner = null`).
- 포획 승리: 흑 **12개**, 백 **10개** 이상. 같은 수에 포획 승리와 5목을 함께 달성하면 `winReason = "capture"`(처리 순서상 먼저), 5목 줄도 기록.
- 판 크기는 설정값(기본 15, 5~25). 같은 화면·AI 대국은 13/15/19 선택 가능. 온라인 대국은 15×15로 고정.
- 무르기: 매 수의 불변 스냅샷을 이력으로 보관 → 돌·따낸 돌·포획 수·차례·승패가 모두 복원.

| 상대가 ?일 때 | 그 판의 결과를 덜 믿는다 → 확정된 고수가 ? 유저에게 져도 조금만 깎인다(예: 2050점이 ? 유저에게 지면 약 7점) |

| 정기 보정 | 하루 1회: 9단 비율이 0.05~0.1%를 벗어나면 1500점 기준으로 폭 조정(1회 최대 ±5%, 순위 불변) |

## AI (src/ai)

알파베타 수읽기 + 형세 판단(5칸 창 줄 모양, 따내기 진행도, 따일 위험). 규칙 판정은 엔진(src/game)을 그대로 쓴다.
브라우저 Web Worker에서 돌아 화면이 멈추지 않는다. 가장 센 단계도 한 수 0.3초 안팎.
화면의 "AI 대국"은 점수에 반영하지 않는다. 레이팅매치에서 AI와 붙으면(서버가 둠) 점수에 반영된다.

| 이름 | 출시 전 추정 급수 | 측정 간격 |
|---|---|---|
| AI 아이언 | 18급 (500) | 기준(추정) |
| AI 브론즈 | 16급 (690) | +188 |
| AI 실버 | 12급 (900) | +211 |
| AI 골드 | 10급 (1070) | +167 |
| AI 플래티넘 | 7급 (1250) | +188 |
| AI 다이아 | 3급 (1490) | +236 |
| AI 마스터 | 5단 (2150) | AI끼리 +236, 사람 시험 대국으로 상향 |
| AI 챌린저 | 8단 (2400) | AI끼리 +236, 사람 시험 대국으로 상향 |

- AI 이름에는 급수를 넣지 않는다. 급수는 AI 계정의 현재 점수에서 자동으로 나오고(사람처럼 지면 떨어진다), 화면의 기력 선택에도 그 급수가 보인다.
  마스터·챌린저는 엔진 강화로 단 수준이 되면 붙인다.
- 레이팅매치: 다른 사람과 대국 중인 AI는 매칭하지 않는다(비어 있는 AI 중 가장 가까운 3개에서 무작위).

- 간격: 이웃 단계끼리 흑백 번갈아 40판 → 승률을 실력 점수 공식(SCALE 350)으로 환산(단계당 오차 약 ±80점).
  `node scripts/calibrate-ai.ts <약한 번호> <강한 번호> [판 수]`
- 출발점(가장 약한 단계 = 18급)은 추정. 사람과의 대국이 쌓이면 실측으로 고친다.
- 고속 엔진(src/ai/fast.ts·fastSearch.ts): AI 전용 놓기/되돌리기 판 + 바뀐 부분만 갱신하는 형세 점수 + 같은 판 기억 + 강제수 연장.
  규칙은 차등 테스트(무작위 1000판, 매 수 판·포획·승패·무승부·되돌리기·해시 비교)로 규칙 엔진과 같음을 확인. 한 수 0.4초에 평균 5수 안팎 읽음.
- 형세 가중치 자동 조정(scripts/tune-eval.ts, Texel 방식): 고속 AI끼리 대국한 조용한 형세로 "형세 → 승패" 예측을 맞춘다.
  1회차 +146점(40판 72.5%), 2회차 +52점(57.5%) 채택. 위협 자리 특징을 더한 3회차는 약해져(40%) 미채택.
- 열린 셋 수순 탐색(VCT): 상대의 모든 응수로 검증해 보니 "필승" 판단 7번 중 5번이 거짓(상대가 역공 셋·다른 곳 끊기로 버팀) → 미채택·코드 삭제.
  정확하게 만들려면 모든 응수를 따져야 해서 한 수 0.4초 안에 끝나지 않는다.
- 강화 실험 기록(각 20~40판, 오차 단계당 ±80~100점): 연속 위협 탐색(공격) 효과 없음, (방어) 역효과,
  후보 수 8/16·시간 1초는 +60~130처럼 보이나 오차 범위, 형세에 "따낼 수 있는 자리" 반영은 효과 없음.
  AI끼리 대국은 대부분 오목으로 끝나고 따내기 승리는 드물다(측정 200판 중 약 5%).

## 아직 정하지 않은 것 (지시서에 없어 임의로 보완하지 않음)

- 판이 가득 차서 둘 곳이 없을 때(무승부 규칙 없음): 대국이 끝나지 않은 채 멈춘다.
- 상대의 포획으로 내 6목이 정확히 5목이 된 경우: 내 착수로 만든 5목이 아니므로 승리 처리하지 않는다(착수점 기준 판정).
- 비밀번호 찾기(이메일), 회원 탈퇴, 관전은 아직 없다.
- 오래 쉬었다 돌아온 유저의 불확실도(rd)를 다시 키우는 처리는 아직 없다.
